Pertanyaan Seputar Konsultasi

Informasi singkat mengenai proses setelah Anda menghubungi kami.

Setelah kirim pesan, apa langkah selanjutnya? expand_more

Tim ahli energi surya kami akan meninjau pesan Anda dan membalas dalam waktu maksimal 1x24 jam kerja. Kami akan mengatur jadwal diskusi awal via telepon atau video call untuk memahami kebutuhan energi dan kondisi lokasi Anda secara spesifik sebelum menjadwalkan survei teknis.

Apakah survei lokasi berbayar? expand_more

Untuk area Jabodetabek, survei lokasi awal tidak dikenakan biaya (gratis). Untuk area di luar Jabodetabek, biaya survei akan didiskusikan terlebih dahulu dan dapat diakumulasikan ke dalam nilai proyek jika Anda memutuskan untuk menggunakan layanan kami.

Bisa konsultasi tanpa datang ke kantor? expand_more

Tentu saja. Mayoritas proses konsultasi awal kami dilakukan secara daring (online) untuk kenyamanan Anda. Kami menggunakan data satelit awal untuk estimasi kapasitas atap sebelum tim teknis melakukan kunjungan fisik.
